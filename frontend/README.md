# Airbell · Frontend

La guía completa de instalación, demostración, seguridad, pruebas y despliegue está en [el README del proyecto](../README.md).

```powershell
npm ci
npm run demo
```

Para trabajar con la API real: `npm run dev`. Para verificar: `npm test` y `npm run build`.
